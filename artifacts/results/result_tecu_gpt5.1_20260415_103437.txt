## RECOMMENDATIONS

1. **Implement/Expose Required Field Validation**
   - Add visible inline error messages for:
     - First Name, Last Name, Email ID, and Mobile Number when left blank.
   - Ensure errors are associated with fields via `aria-describedby` or similar for screen readers.

2. **Add Robust Email Validation**
   - Enforce a basic email pattern and show an inline error like “Please enter a valid email address.”
   - Consider normalizing case (already uppercasing) but validate before saving.

3. **Clarify and Harmonize Name Field Rules**
   - Decide whether digits and special characters are allowed:
     - If not allowed: show a clear error message instead of silently stripping them.
     - If allowed (to handle edge-case names): stop auto-stripping and accept the input as typed.
   - Update helper text or placeholder to indicate allowed characters if restricted.

4. **Improve Mobile Number Handling**
   - If only 7-digit local numbers are allowed:
     - Add helper text like “Enter 7-digit local number” and show error when not exactly 7 digits.
   - If longer numbers can be entered:
     - Adjust mask/formatting to retain all digits (e.g., full 10-digit number) or explicitly reject overlong inputs with an error instead of truncating.
   - Always avoid silent truncation; users should clearly understand what will be saved.

5. **Profile Picture Upload**
   - Expose or ensure a detectable `<input type="file">` for automated testing.
   - Provide user feedback after successful upload (thumbnail, filename, or status text).

6. **Accessibility & UX**
   - Ensure all error messages:
     - Use consistent styling and placement.
     - Are announced via ARIA live regions when they appear.
   - Confirm that labels and required markers (`*`) are announced properly by screen readers.
   - Consider showing inline hints for formats (email, phone) directly under the fields.

7. **Areas for Deeper Testing**
   - Boundary conditions: maximum lengths for names, email, and phone.
   - Internationalization: characters with accents, apostrophes, or hyphens in names.
   - Full navigation flow: how Save & Exit and Save & Continue behave with invalid or empty required fields (once navigation is allowed in a different test run).
